# Charge Tally

[English](README.md) · **简体中文** · [Deutsch](README.de.md) · [Français](README.fr.md) · [Polski](README.pl.md) · [Italiano](README.it.md)

在 Home Assistant 中按充电点和身份记录充电电量、费用，并核对每次充电的计费过程。Charge Tally 使用你已有的电量或功率传感器；它负责记账，不控制充电器开关。

- 一个账本管理多个充电点；车辆、驾驶人或家庭成员可作为所有充电点共享的身份。
- 支持累计电量、功率计算电量，以及电量计量配合功率识别。
- 支持固定、动态和每日分时电价，包括零电价、负电价。
- 自动识别充电，或通过卡片、Home Assistant 自动化开始和结束记账。
- 查看实时充电、今日／本月／本年／累计／自选范围统计及按范围分组的图表。
- 补录历史、修改已结束记录、调整身份、作废错误记录，并查看计费分段和修订历史。
- 管理归档充电点和身份，永久清理不再需要的账本数据。

主要操作有两个入口：**设置 → 设备与服务 → Charge Tally** 管理配置；仪表盘上的 **Charge Tally** 卡片查看和操作记录。卡片在同一页面展示多个区域，记录详情和编辑在弹窗中打开。

## 当前卡片与记账行为

每次打开页面时仅展开充电控制，统计和充电记录默认收起。页面内的实时更新保留已展开区域和控件状态；重新加载页面恢复默认。展开统计后加载图表，展开充电记录后加载历史列表。

图表按范围分组：今日按小时、本月按天、本年按月、累计按年。自选范围按当地日历日期差自动分组：不超过 2 天按小时，不超过 90 天按天，不超过 730 天按月，超过 730 天按年。时间桶遵循账本时区及夏令时。电量和已知费用图表与汇总使用同一范围，未知费用不会当作零。

预览和记录详情中的计费分段会合并计费依据、电价和质量状态相同的相邻区间，用于理解账单，并非每次电表上报的采样明细。时间范围统计仍使用原始采样明细。修改记录在开始、结束或显式修改（包括调整身份、作废）时保存快照；日常采样只更新当前记录，不逐次增加修改快照，因此修订编号可以不连续。

移除充电点配置后，未结束记录仍保留。需要清理时，在主集成的**配置 → 管理归档数据 → 已归档充电点**中选择已移除的点，核对未结束数量及影响范围，再明确确认永久删除；取消确认会保留记录。清理包括该点的记录、修改快照、采样及电价，不删除 HA recorder 数据或备份。

当前开发账本格式已变化。较早的不支持格式会被拒绝，不会自动迁移或删除。一次性开发测试账本可能需要在备份后重新创建；升级集成本身不会执行清理。

## 安装前准备

需要 **Home Assistant 2025.9.0 或更新版本**，以及至少一个测量充电线路的传感器。安装和配置请使用管理员账户。界面会跟随 Home Assistant 的语言；本文使用简体中文界面实际显示的名称，通用菜单的位置可能随 HA 版本略有不同。

| 已有数据 | “用电输入模式”选择 | 用途 |
| --- | --- | --- |
| 单位为 Wh、kWh 或 MWh 的累计电量 | **仅电量** | 根据电表读数记账；通过卡片或自动化开始、结束记账 |
| 单位为 W 或 kW 的功率 | **仅功率（原生 Integral）** | 自动创建 Home Assistant 辅助元素计算电量，也可启用智能识别 |
| 累计电量和功率都有 | **电量加功率** | 用电量传感器计量、用功率识别；不会重复累加两者的电量 |

累计电量应是通常递增、或归零后重新递增的电表读数，而不是“最近一小时用电量”。传感器应在 Home Assistant 中正确标识为电量或功率，并提供有效的非负数值；同一来源不能重复分配给多个充电点。

如果使用动态电价，先准备与账本币种一致的电价传感器。如果需要从传感器历史补录，请确认 Home Assistant 会记录这些传感器，且所需日期仍在历史保留范围内。

## 安装集成

### 方式一：通过 HACS

尚未安装 HACS 时，先按照 [HACS 官方安装说明](https://hacs.dev/docs/use/download/download/)完成安装和配置。

**一键添加到 HACS：**

[![在 HACS 中打开 Charge Tally](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=enecess&repository=ha-charge-tally&category=integration)

点击按钮，按提示填写或确认你的 Home Assistant 地址，在 HACS 中添加或打开 Charge Tally。完成后从下方第 3 步继续下载、重启和添加集成；也可以从第 1 步开始手动添加仓库。

1. 打开 **HACS**，点击右上角菜单，进入 **自定义存储库**。
2. 添加仓库 `https://github.com/enecess/ha-charge-tally`，类型选择 **集成**。
3. 搜索并打开 **Charge Tally**，下载需要的版本。
4. 下载完成后，**重启 Home Assistant**。
5. 进入 **设置 → 设备与服务 → 添加集成**，搜索并选择 **Charge Tally**。
6. 继续下方的“首次配置”。HACS 下载完成不代表账本和充电点已经创建。

> 截图占位 02：HACS 自定义存储库、Charge Tally 下载页，以及“添加集成”搜索结果。

### 方式二：手动安装

1. 下载本仓库并解压，找到其中的 `custom_components/charge_tally` 文件夹。
2. 打开 Home Assistant 的配置目录，也就是存放 `configuration.yaml` 的目录。
3. 若没有 `custom_components` 文件夹，先创建它；将整个 `charge_tally` 文件夹复制进去，保留其中所有子目录。
4. 确认最终文件位置为 `custom_components/charge_tally/manifest.json`，避免多嵌套一层仓库目录。
5. **重启 Home Assistant**，再进入 **设置 → 设备与服务 → 添加集成 → Charge Tally**。

卡片已随集成一起提供，无需再通过 HACS 单独安装前端卡片。安装后找不到集成时，先确认目录层级和重启是否完成，再刷新页面并查看 Home Assistant 日志。

## 首次配置

### 1. 创建账本

在 **Charge Tally 账本** 窗口中选择 **币种**。下拉菜单包含 Home Assistant 支持的全部币种，显示本地化名称和 ISO 代码，例如人民币(CNY)，并按当前界面语言的名称排序。首次默认选中 Home Assistant“家庭详情”中的系统币种。每个 Home Assistant 使用一个 Charge Tally 账本，所有充电点和记录共用此币种。

- 无充电点（包括归档点）且无保留记账数据时，可以修改币种；仅添加身份不会锁定。
- 添加充电点后，即使还没有充电，也会锁定币种。
- 删除单个充电点或身份配置会保留历史；彻底清理全部充电点及相关数据后才可再次修改币种。
- 删除整个集成会永久清除账本及集成自有数据。重新添加时，将按所选币种创建全新账本。
- 提交此表单时，也会清除旧版本删除集成后遗留的账本文件。

> 截图占位 03：“Charge Tally 账本”窗口及分行币种说明。

### 2. 添加充电点

创建账本后，支持自动续接流程的 HA 版本会打开充电点窗口。如果没有自动打开，进入 **设置 → 设备与服务 → Charge Tally → 添加充电点**。

在 **充电点** 页面填写 **名称**，例如“车库”，再选择 **用电输入模式**。一个充电点代表一组独立计量的充电线路。

### 3. 选择用电数据

在 **用电数据** 页面展开 **计量与识别**，按所选模式填写：

| 界面字段 | 如何填写 |
| --- | --- |
| **累计电量实体** | 选择测量该线路累计用电量的传感器；“仅功率（原生 Integral）”不显示此项 |
| **功率实体** | 选择该线路的功率传感器；“仅电量”不显示此项 |
| **表底可能重置** | 电表可能归零时保持开启；读数下降会按重置处理，并标记对应区间不完整 |
| **最大自动分摊间隔（秒）** | 默认 600 秒；超过此间隔的读数区间会被标记为数据缺口，需复核 |
| **智能充电识别** | 含功率的模式才显示；开启后继续填写识别参数 |

### 4. 设置智能识别（可选）

开启 **智能充电识别** 后，进入 **智能识别参数**：

- **开始阈值（W）**：功率达到或超过此值，开始确认充电。
- **开始持续时间（秒）**：持续满足后创建记录，默认 30 秒。
- **结束阈值（W）**：功率低于此值，开始确认结束；必须低于开始阈值。
- **结束持续时间（秒）**：持续满足后结束记账，默认 300 秒。

阈值按充电器的实际待机和充电功率设置。确认完成后，记录时间回溯到开始满足条件的时刻；短暂停顿未达到结束持续时间时，仍属于同一条记录。开始确认完成前仍可选择身份，新选择用于本次充电，开始时间和确认进度不变。

不开启识别也能记账，之后使用 **手动开始记账** 和 **结束记账**。

> 截图占位 04：“用电数据”中的“计量与识别”，以及“智能识别参数”窗口。

### 5. 配置电价

**电价模式** 下拉框有以下选项，后续窗口名称与选项略有不同：

| 选项 | 后续窗口 | 填写内容 |
| --- | --- | --- |
| **固定** | **固定电价** | **每 kWh 单价**，使用账本币种 |
| **动态实体** | **动态电价** | **电价实体**，必要时填写 **确认单位** |
| **每日分时** | **每日分时电价** | 逐条配置一天内的电价时段 |

固定和分时单价允许零或负值。动态电价可以使用账本币种每 Wh、kWh 或 MWh，集成会统一计量单位；不会换算币种。只有来源没有单位时，才需用 **确认单位** 补充。来源已有错误币种或单位时，不能用此项覆盖。

设置 **每日分时电价** 时：

1. 在 **操作** 中选择 **添加时段**。
2. 在 **编辑电价时段** 中填写 **开始时刻**、**结束时刻（24:00 为当天结束）** 和 **每 kWh 单价**。
3. 重复添加需要的时段；修改或删除时，先选择 **时段**，再选 **编辑时段** 或 **移除时段**。
4. 完整覆盖一天后，选择 **完成时段配置**。

时间使用 `HH:MM`；例如 `00:00–08:00`、`08:00–22:00`、`22:00–24:00`。也支持 `22:00–06:00` 这样的跨午夜时段。不能重叠、留空或使用相同起止时刻；全天可填 `00:00–24:00`。此时间表每天重复，不区分工作日和周末。

> 截图占位 05：电价模式选择、动态电价单位确认、每日分时电价列表及编辑时段窗口。

### 6. 核对周期统计与摘要

在 **周期统计与摘要** 核对充电点名称、用电输入模式和电价模式，再选择 **电量统计周期** 中的 **日／月／年**，默认全选，也可以不选。

这些选项决定是否创建额外的原生电量统计辅助元素，不控制卡片的“记录统计”或身份统计是否可用。完成配置后，确认充电点已出现在集成页面、来源传感器正常，且没有“辅助元素需要修复”的提示。

> 截图占位 06：“周期统计与摘要”及配置完成后的 Charge Tally 集成页面。

## 身份与后续配置

在 **设置 → 设备与服务 → Charge Tally** 中使用对应入口：

| 入口 | 用途 |
| --- | --- |
| **添加充电点** | 增加另一组独立计量的充电线路 |
| **配置充电点** | 修改该点名称、传感器、识别、电价和统计周期 |
| **添加共享身份** | 为车辆、家人或其他对象创建身份 |
| **配置身份** | 修改名称，或切换 **启用** |
| 主集成 **配置** | 打开 **账本设置** 和 **管理归档数据**; **NFC 身份联动** |

**共享身份** 窗口只有 **名称** 和 **启用**。身份跨充电点共用，名称不能与其他已配置身份重复。内置 **Unassigned** 用于未分配的记录，实际下拉框保留这个英文名称。

改名后历史记录仍属于同一身份。取消 **启用** 后，该身份不能用于新的身份选择，但历史仍保留；删除身份配置后，同样保留历史，之后才能在归档管理中永久移除它。停用与删除配置不是同一操作。

更改计量或识别设置前，先结束当前记录，并等待“正在确认充电／正在确认结束”状态结束。修改电价从修改时刻起生效，不会把已记录金额按新价重算。删除充电点前也应先结束记账，删除配置不会自动结算正在进行的充电。

> 截图占位 07：“添加共享身份／配置身份”窗口，以及充电点与主集成各自的配置入口。

## 添加与设置仪表盘卡片

1. 先完成至少一个充电点的配置，再打开要放卡片的仪表盘。
2. 进入编辑模式。分区布局使用分区内的加号，其他布局使用 **添加卡片**。
3. 按卡片类型搜索 **Charge Tally** 并选择它。
4. 使用可视化编辑器设置下表选项，保存卡片并完成仪表盘编辑。

| 编辑器字段 | 作用 |
| --- | --- |
| **标题** | 自定义卡片标题，留空显示 Charge Tally |
| **充电点** | 卡片初始选择的充电点，或 **全部** |
| **身份筛选** | 卡片初始选择的身份，或 **全部** |
| **显示记录** | 显示／隐藏记录列表及列表上的“补录”入口 |
| **显示图表** | 显示／隐藏统计柱状图，不影响统计数值 |

可以放置多张卡片，分别选择不同充电点或身份。这些只是显示筛选，不是账户权限设置；用户仍只能访问 Home Assistant 授权的数据。卡片支持简体中文、英语、德语、法语、波兰语、意大利语，并跟随主题。

> 截图占位 08：添加 Charge Tally 卡片及可视化编辑器的五项设置。

### 卡片未出现在列表中

先确认 Charge Tally 集成已加载，再刷新浏览器。通常使用界面管理仪表盘资源时，集成会自动注册卡片，不必手动添加。

如果仍需手动登记，在 **设置 → 仪表盘** 的菜单中打开 **资源**；若入口未显示，先在用户个人资料中启用 **高级模式**。添加以下资源后刷新页面：

| 字段 | 内容 |
| --- | --- |
| URL | `/charge_tally/charge-tally-card.js?v=0.1.2-8` |
| 资源类型 | **JavaScript 模块** |

已有相同路径的资源时更新它，避免重复添加。自行用 YAML 管理资源的用户，在自己的资源配置中登记同一地址与模块类型；不要再安装第二份卡片。资源管理方式见 [Home Assistant 仪表盘文档](https://www.home-assistant.io/dashboards/dashboards/)。

## 卡片页面说明

### 顶部连接状态与筛选

标题旁显示 **已连接**，或 **已断开 · 等待最新快照**。断线后可以在连接恢复时使用 **重试**，不要把旧显示当作最新计费结果。

**充电点** 和 **身份筛选** 用于统计及记录列表。充电点选择还决定显示哪些实时面板；身份筛选不会改动充电点当前选择的身份。保留历史的对象可能带 **已归档** 标记：归档点可查历史，但不会显示可开始充电的实时面板。停用身份也可能显示此标记，能否永久删除仍以集成配置中的归档管理为准。

### 充电点实时面板

面板分别显示记账状态、**功率**和**自动识别**状态。**未记账**、**手动记账中**、**自动记账中**描述账本记录；有活动记录并不代表充电器正在耗电。自动识别单独显示等待、确认、手动记账期间暂停、数据不可用或等待功率回落等状态。

确认充电期间，**本次待确认身份**显示当前候选身份。**本次待确认/手动记账身份**选择用于本次待确认充电或立即手动开始。确认完成前切换身份会用于本次充电；开始时间和确认进度不变。已生成记录保持原身份。

每个当前充电点显示名称、状态、**功率**、**当前单价** 和 **自动识别** 状态。没有可用功率或价格时相应数值可能为空。卡片上的“自动识别”是状态显示，调整识别请使用充电点配置或原生 **充电检测** 开关。

| 界面内容 | 含义 |
| --- | --- |
| **当前选择身份** | 没有活动记录时，选择本次待确认充电或下一次充电的归属 |
| **本次身份** | 当前活动记录已经归属的身份 |

### 记录统计与图表

## 充电记录的日常操作

### 手动开始和结束

1. 选择对应充电点的身份，点击 **手动开始记账**；正在确认充电时，按钮为 **立即开始记账**。
2. 确认显示 **手动记账中** 和当前累计。立即手动开始使用当前选择身份，并清除自动候选。
3. 点击 **结束记账**，再从列表打开记录核对。

这些按钮只记录起止时间，不会启停充电器。手动开始的记录必须通过卡片或自动化动作显式结束。自动识别在这条记录期间暂停，即使功率为零也不会自动结束。开始需要有效的电量计量基线；已有记录在计量不可用时仍可结束。

### 自动识别充电

配置并开启自动识别后，识别状态可能依次显示 **正在确认充电 → 正在跟踪自动记录 → 正在确认结束 → 等待自动识别**。确认期间功率条件不再满足，会取消相应候选。自动确认采用确认完成前最后一次成功选择的身份，包括 **Unassigned**。自动记录可通过 **手动结束记账** 提前结束；正在确认结束时，按钮为 **立即结束记账**。

显式结束后，识别通常等待功率低于结束阈值。只有最近一次有效低功率观测不晚于结束命令、距命令的时长不超过 **最大自动分摊间隔（秒）** 设置的有效时长上限，且未因数据不可用或重启而失效，才可立即恢复自动识别。高功率、缺失、未来或过期观测都不能解除阻止；功率为 `unknown` 或不可用之后，必须收到后续有效低功率观测才能恢复。等待功率回落期间仍可手动开始记账。

通过原生 **充电检测** 开关暂停识别前，应先结束活动记录并等待候选状态结束。首次尚未填写阈值时，请回到 **配置充电点** 完成设置。

### 查看详情和修订

详情包含记录归属、电量、费用、起止时间、记账时区、**状态**、**来源**、**版本**、备注及质量提示。

- **计费分段**：查看各段时间、电量、费用和 **数据质量**，适合检查跨日或电价变化时的分配。
- **修订历史**：展开查看各版本的身份、状态、金额和备注；这是审计记录，没有一键回滚按钮。
- 活动记录可以 **修改本次身份**；只有已结束记录才显示 **编辑记录** 和 **作废记录**。

> 截图占位 12：已结束记录详情，包含计费分段、展开的修订历史和操作按钮。

### 更正身份

打开记录详情并选择 **修改本次身份**，在 **归属身份** 中选择正确身份，点击 **保存预览**。这个弹窗的提交按钮目前就叫“保存预览”，不需要先执行另一项“预览修改”。转移整条记录的归属，电量和金额不重新计算。

### 作废错误记录

在已结束记录详情中选择 **作废记录**，核对后点击 **确认作废**。该记录会退出统计和普通记录列表，但账本仍保留原记录及修订。界面没有“显示作废记录”或恢复按钮；作废不等于永久删除数据。

## 补录与编辑历史记录

从 **补录** 打开 **新增历史记录**；修改已有记录则先打开已结束记录，再选择 **编辑记录**。

1. 核对窗口中的 **记账时区**，选择 **充电点** 与 **归属身份**。新增记录应选择当前充电点与启用身份；即使列表里出现归档点，也不能为其新增记录。编辑已有记录时，充电点固定，不能改成另一个点。
2. 输入 **开始** 和 **结束（不含）** 的日期及时间，结束必须晚于开始。
3. 填写或留空人工电量，并选择费用依据，见下表。
4. 按需填写 **备注**，最多 2000 字符。
5. 点击 **预览修改**，查看 **预览 · 核对后保存**，确认修改后的金额、计费分段、数据质量及 **计量覆盖范围**；编辑已有记录还会显示 **修改前／修改后**。
6. 核对没有重叠记录后点击 **保存预览**。修改表单后需重新预览；直接 **关闭** 不保存。

| 字段或选项 | 行为 |
| --- | --- |
| 补录的 **人工电量（kWh，留空使用历史）** | 留空尝试使用可用计量历史；填写则使用该总电量 |
| 编辑的 **人工电量（kWh，留空保留原依据）** | 留空保留原依据，不是清除原人工电量 |
| **费用依据 → 使用可用历史和电价** | 补录时的默认选项；依赖实际可用的历史数据和电价 |
| **费用依据 → 保留原费用依据** | 编辑时的默认选项，避免把简单备注修改误当作重新定价 |
| **费用依据 → 人工总费用** | 启用 **人工总费用** 输入框，填写已知总金额，可为零或负值 |
| **费用依据 → 待补充** | 明确将费用保留为未知，不会按免费处理 |

同一充电点的记录不能在时间上重叠。预览列出重叠记录时不能保存；如果提示预览过期或记录已变更，刷新并重新预览。

补录历史取决于 Home Assistant 和账本仍保留的数据，不保证能恢复任意旧日期。缺少数据时可参考充电器账单填写人工总电量和费用。人工总量或总费用需要按时间分配到分段，出现 **人工覆盖／估算** 是对计算依据的提示。

日期时间按显示的记账时区解释，而非浏览器所在时区。遇到夏令时重复的当地时间，需要在 **重复当地时间：选择 UTC 时刻** 中选择对应时刻；不存在的当地时间不能提交。

## 理解统计和数据质量

| 提示或现象 | 如何理解 |
| --- | --- |
| **暂计／待结算** | 当前记录或计量边界尚未完全确定，之后读数可能更新结果 |
| **已知小计 · 待补充** | 显示的只是已知费用，不是完整账单，未知部分不是零 |
| **缺少电价／电价未知** | 相应时段没有有效价格；检查来源币种、单位、可用性和历史保留 |
| **缺少电量／观测缺口** | 数据不足或读数间隔过长，需复核，必要时人工补录 |
| **电表重置** | 读数下降导致相关区间不完整 |
| **人工覆盖／估算** | 使用了人工值或按时间分配，不能理解为逐时实际测量 |

记录电量按所属时间拆分到日、月、年，跨午夜的充电不会全部计入开始那天。历史记录保留自己的记账时区。**已完成** 数量按记录开始时间归入所选范围，因此跨界记录可能贡献部分电量，但不增加该范围的已完成数量。

卡片和身份统计只汇总充电记录；原生电量统计也可能包括待机等未被记录包住的耗电，两者不一定相等。修改记录会更新账本统计，不会改写 Home Assistant 原生电表历史。费用图表展示已知金额；显示的小数位数不改变账本保存精度。

## 原生实体与自动化

除了专用卡片，也可以在 Home Assistant 的实体页面、其他卡片和自动化中使用集成提供的数据。以下以充电点“车库”和身份“家庭用车”为例，实际名称会随你填写的名称变化。

| 可见实体 | 用途 |
| --- | --- |
| **车库 电量** | 该充电点的累计电量 |
| **车库 状态** | 当前充电或可用性状态 |
| **车库 记录电量／车库 记录费用** | 当前活动记录；没有活动记录时无当前值，不代表上一笔 |
| **车库 身份** | 为下一次记录选择身份，可配合 RFID、按钮等自动化 |
| **车库 充电检测** | 含功率模式下的智能识别开关，不控制充电器供电 |
| **家庭用车 今日电量／今日费用、本月电量／本月费用、今年电量／今年费用、累计电量／累计费用** | 该身份的记录统计；Unassigned 也有对应统计 |

费用不完整时，原生费用实体可能没有完整数值，而卡片仍能展示已知小计。配置充电点时选择的日／月／年电量辅助元素与以上身份统计是不同用途；不要手动删除或改动集成创建的受管理辅助元素。

自动化的动作选择器提供 **Charge Tally：开始记账／结束记账／修改记录身份**。开始和结束按服务器当前时刻执行，不能用来补填历史起止时间；历史补录请使用卡片。

这些记账动作还要求按表单提供 **请求 ID**，结束和修改归属要求 **预期记录版本**；它们不是只选择一个设备即可完成的普通开关动作。每次新操作使用不同请求标识，重试同一操作保持原标识和参数。只需改变下一次身份时，优先操作 **车库 身份**；需要直接记账且不熟悉这些校验字段时，使用卡片上的按钮。

## 管理归档数据与币种

### 删除配置、作废和永久清理的区别

| 操作 | 结果 |
| --- | --- |
| 停用身份 | 不再供新的身份选择使用，配置及历史保留 |
| 删除充电点或身份的配置项 | 保留账本历史，成为归档管理的候选对象；停用并不等于删除配置 |
| 作废某条记录 | 从普通列表和统计排除，审计数据保留 |
| 管理归档数据中的永久操作 | 实际清理账本对象和相关数据，界面无法撤销 |

### 永久清理归档充电点

1. 打开主集成 **配置 → 管理归档数据 → 归档充电点**。
2. 在 **选择归档对象** 中选取一个或多个已删除配置的充电点。
3. 在 **确认永久操作** 核对对象、操作、记录数（含作废）、修订数、UTC 时间范围、电量和已知费用。
4. 勾选 **我已了解影响并确认永久删除**，再提交。完成后显示 **归档操作完成** 和删除条数。

此操作删除该点的账本记录、关联修订、采样及电价历史，不是只隐藏一个名字。

### 永久移除归档身份

进入 **配置 → 管理归档数据 → 归档身份**，选取一个或多个对象。只要任一所选身份有记录，就先在 **转移身份记录** 中选择同一个 **接收身份**，可以是启用的现有身份或 **Unassigned**；均无记录时直接进入确认。

所有选中对象作为一批处理。任一对象发生变化或操作失败时，整批都不会修改。

记录包含作废记录，会整体转移且金额保持不变。原身份被删除，旧修订保留其原名称供审计。内置 Unassigned 不能删除。对象仍在使用或确认期间数据发生变化时，操作会被阻止，需要先处理活动记录或重新打开预览。

归档清理只作用于 Charge Tally 账本，**不会清除 Home Assistant 原生历史、长期统计或备份**。确认页面的电量和已知费用包含所列作废记录，用于描述处理范围，不应与排除作废记录的日常统计直接比较。

> 截图占位 14：归档类别、对象选择、身份转移及永久操作确认窗口。

### 修改币种

打开主集成 **配置 → 账本设置**。下拉菜单默认选中账本当前币种；Home Assistant 系统币种的后续变化不会改变这一默认值。只有没有充电点（含归档点）且无保留记账数据时，才显示可修改币种的表单；否则显示 **账本币种已锁定** 及处理说明。仅保留身份不会锁定。

需要重新开始使用另一币种时，先完成必要备份，再删除不再使用的充电点配置，并通过归档管理清理其相关数据，最后重新打开账本设置。这个过程是清空后重新选择币种，不会把历史金额换算成新币种。

## 更新备份与恢复

1. 更新前创建包含 Home Assistant 配置目录的备份。
2. HACS 安装的用户在 HACS 更新；手动安装的用户更新整个集成文件夹，保留完整目录结构。
3. 重启 Home Assistant，再刷新浏览器或应用中的仪表盘。自行管理资源时，同时核对上方资源地址的版本。
4. 检查充电点状态、记录和统计；若提示修复辅助元素，按修复流程处理。

账本保存在 Home Assistant 配置目录内。HA 创建备份时，集成会准备一致的账本副本。删除整个集成会永久清除账本、内部备份及集成自有设置；重新添加时可选择任意合法币种，创建全新账本。重启、重载和更新会保留数据，仅卸载程序文件不会执行清理。HA 原生历史、长期统计、外部备份及用户自动化不会删除。恢复备份应同时恢复相应配置和账本。

本地品牌图标在 **Home Assistant 2026.3 及更新版本**支持；较旧版本的图标显示不影响记账功能。

## 常见问题

| 遇到的问题 | 检查方法 |
| --- | --- |
| 下载后找不到 Charge Tally | 确认安装的是集成，目录没有嵌套，已重启；在“添加集成”中搜索，而非只在卡片列表找 |
| 找不到卡片 | 先让集成成功加载，刷新前端；再核对“资源”中的地址和 JavaScript 模块类型 |
| **暂无可访问充电点，请配置 Charge Tally 或检查权限。** | 确认至少有一个点且当前用户有读取权限；仅有身份不会产生实时充电点 |
| 没有自动生成记录 | 确认有功率来源、已完成智能识别设置、开关开启，且阈值与持续时间确实满足 |
| “手动开始记账”不可用 | 检查计量来源和充电点身份实体是否可用，以及集成是否仍在加载或修复 |
| 切换身份后本次记录未变化 | 下拉框为下一次准备身份；更正现有记录应使用“修改本次身份” |
| 选择“今日”仍看到旧记录 | 统计周期只作用于统计；“记录 · 全部日期”不按统计日期筛选 |
| 费用只有已知小计或原生费用实体无值 | 检查计量缺口、历史电价及币种；在详情中核对质量，不要按免费处理 |
| 预览过期、记录已变更或时段重叠 | 刷新后重开记录并重新预览；重叠时调整起止时间，不能跳过检查保存 |
| **充电点辅助元素需要修复** | 打开 HA 的修复提示，进入 **修复辅助元素** 并确认；将重建本集成拥有的异常辅助元素，保留历史记录 |
| 已删除配置但币种仍锁定 | 配置删除会保留归档数据；到“管理归档数据”检查是否仍有点或记账数据 |
| 普通账户看不到归档点或不能操作 | 检查 HA 的读取／控制权限，归档管理使用管理员账户；卡片筛选不能授予权限 |

## NFC 身份联动

管理员打开 **设置 → 设备与服务 → Charge Tally → 配置 → NFC 身份联动**，进入管理页面。先在 HA 注册标签，再选择标签、充电点、扫描设备与身份；可以添加多个设备映射，也可以只设置默认身份。每个“标签 + 充电点”只有一条托管自动化。同一标签绑定多个点时，一次扫描会分别作用于这些点。

设备专属映射优先；其他设备使用默认身份，未设置默认则不操作。刷卡选择记账身份；开始确认完成前，新选择用于本次充电，开始时间和确认进度不变。已生成记录保持原归属。身份改名不影响绑定；存在已删除标签、设备、充电点或停用身份时，整条联动停止选择身份，需修复映射，不会回退到另一个身份。

自动化名称带有 **Charge Tally 托管**，说明中提供管理入口。请在集成内编辑映射，在 HA 查看执行记录或暂停自动化。集成保存时保留暂停状态；HA 原生实体 ID 重命名可能自行恢复开启，请在改名后检查 HA 的开关状态。外部修改显示冲突，需明确选择 **恢复集成配置**；外部删除显示缺失，需选择 **重新创建自动化**。网络中断后使用 **继续待完成操作**，不会新建第二条自动化。

恢复或重建前可以先修复失效的映射；覆盖外部修改需要再次确认。待删除操作尚未删除自动化时，可以取消该操作，保留 HA 中的当前配置。

移除整个集成前，可先在该页面删除联动，清理对应自动化。管理页面需要管理员权限及已加载的 HA 自动化和配置组件；不会创建 NFC 标签，也不控制充电器开关。
