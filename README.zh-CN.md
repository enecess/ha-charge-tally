# Charge Tally

[English](README.md) · **简体中文** · [Deutsch](README.de.md) · [Français](README.fr.md) · [Polski](README.pl.md)

在 Home Assistant 中记录充电电量和费用。Charge Tally 使用你已有的电量或功率传感器生成充电记录，并可将每条记录归属于车辆、驾驶人，或你自己命名的其他身份。

- 支持固定电价、动态电价，以及一天内不同时段的电价。
- 自动识别充电，也可以手动开始和结束记录。
- 按身份查看今日、本月和今年的电量与费用。
- 补录以前的充电，并修改记录详情。
- 在仪表盘卡片中查看和操作。

## 开始前的准备

你需要 Home Assistant，以及至少一个测量充电线路用电情况的传感器。Charge Tally 负责记录充电，不会控制充电器的开关。

需要 **Home Assistant 2025.3.4 或更新版本**。已在 2025.3.4、2025.12.4、2026.3.4 和 2026.9.1 上验证。

| 已有的传感器 | 配置时选择 |
| --- | --- |
| 单位为 Wh、kWh 或 MWh 的累计电量 | **仅电量** |
| 单位为 W 或 kW 的功率 | **仅功率**——由 Home Assistant 计算用电量 |
| 两者都有 | **电量加功率**——电量用于计量，功率用于识别充电 |

累计电量是通常持续增加的电表读数，不是最近一小时的用电量。自动识别充电需要功率传感器。

## 通过 HACS 安装

1. 打开 **HACS**，在菜单中选择 **自定义存储库**。
2. 输入 `https://github.com/enecess/ha-charge-tally`，类型选择 **集成**。
3. 在 HACS 中找到 **Charge Tally** 并下载。
4. 重启 Home Assistant。
5. 打开 **设置 → 设备与服务 → 添加集成**，搜索 **Charge Tally**。

如需手动安装，将仓库中的 `custom_components/charge_tally` 文件夹复制到 Home Assistant 的 `custom_components` 文件夹中，然后重启。

## 配置第一个充电点

1. **选择币种。** 所有充电点共用此币种；已有记录的币种之后不能直接更改。
2. **为充电点命名**，选择用电输入模式及对应传感器。
3. 如果有功率传感器，选择是否开启 **智能充电识别**。设置开始和结束的功率阈值，以及功率需要持续达到阈值的时间。结束阈值必须低于开始阈值。
4. 按下表 **设置电价**。
5. 选择需要的日、月、年电量统计，然后完成配置。

如果没有自动打开充电点表单，请在 **设置 → 设备与服务** 中打开 **Charge Tally**，选择 **添加充电点**。

| 电价模式 | 需要填写的内容 |
| --- | --- |
| 固定电价 | 每 kWh 单价 |
| 动态电价 | 与 Charge Tally 使用相同币种的电价传感器 |
| 每日分时电价 | 各时段的开始、结束和单价，完整覆盖一天 |

分时电价每天重复。时段可以跨午夜；一天结束使用 `24:00`。支持零电价和负电价。

要添加其他充电点或身份，请打开 **设置 → 设备与服务** 中的 **Charge Tally**。也可以在这里修改已有充电点的设置。修改计量或识别设置前，请先结束该充电点当前的记录。

## 添加仪表盘卡片

编辑仪表盘，选择 **添加卡片**，搜索 **Charge Tally**。卡片编辑器可选择要显示的充电点、身份和信息。卡片会跟随 Home Assistant 的语言和主题。

卡片通常会自动出现在列表中。如果找不到，先刷新浏览器。如果你自行管理仪表盘资源，请将 `/charge_tally/charge-tally-card.js?v=0.1.2` 添加为 **JavaScript 模块**，然后再次刷新。

## 使用身份和充电记录

身份可以代表一辆车、一位家人，或其他想要单独统计的对象。所有充电点共用身份。没有选择身份时，可以使用 **Unassigned**（未分配）。

请在充电开始前选择身份。记录开始后会保留当时的身份；充电中更改选择，只会用于 **下一条** 记录。如需修改当前或以前记录的归属，请使用 **修改本次身份**。

开启自动识别后，功率达到设定阈值并持续相应时间，记录就会自动开始或结束。短暂停顿可以保留在同一条记录中。未开启识别时，使用卡片上的 **开始记录** 和 **结束记录**。

在自己的自动化中，可以通过充电点的 **身份** 实体选择充电对象。例如，让 RFID 读卡器或按钮更改此选择。自动化的动作选择器也提供 Charge Tally 的开始和结束记账动作。

## 补录或修改以前的充电

1. 在卡片中选择 **补录**，或打开已结束的记录，选择 **编辑记录**。
2. 选择充电点、身份，以及开始和结束时间。
3. 使用现有传感器历史数据，或手动输入总电量。选择费用计算方式；费用尚不清楚时，可以留待补充。
4. 选择 **预览修改**，核对结果后选择 **保存预览**。

能否使用历史数据，取决于 Home Assistant 保留了哪些读数。如果数据缺失，可以从其他来源（例如充电器自身的记录）获取总电量并手动填写。同一充电点的两条记录不能在时间上重叠。

使用 **作废记录** 可将错误记录排除在统计之外，原有详情仍会保留供查阅。

## 如何理解统计数值

- **充电跨午夜：** 电量会分到对应日期；跨月和跨年也一样。如果电表两次读数横跨分界时刻，会按经过的时间估算分配。
- **充电仍在进行：** 随着新读数到来或最终结束时间确认，数值可能变化。
- **费用待补充：** 部分电价缺失。显示的已知金额只是部分费用，并非最终费用。
- **电量表与记录统计可能不同：** 电量表还会计入充电记录之外的用电，例如待机耗电。身份统计只包含归属于该身份的记录。修改记录会更新记录统计，不会改写电量表历史。

## 常见问题

**为什么没有生成充电记录？** 检查所选传感器是否可用。如果使用自动识别，确认已经开启，并且功率超过开始阈值的时间足够长。否则请手动开始记录。

**为什么费用待补充？** 检查电价传感器及其币种，或打开记录填写已知的总费用。缺失数据不会按零费用处理。

**为什么 Home Assistant 提示修复充电点？** 为该充电点创建的某个电量统计传感器可能被删除或修改。打开修复提示并按照说明操作。

**怎样稳妥地更新？** 先备份 Home Assistant，再通过 HACS 更新 Charge Tally，最后重启 Home Assistant。移除集成不会清除已保存的充电记录。
